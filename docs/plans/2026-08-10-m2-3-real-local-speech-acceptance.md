# WordCovenant M2.3 真实本地语音体验验收清单

**目标：** 在真实 macOS 设备上确认 WordCovenant 能在用户主动开始记录后，使用用户
显式导入并选择的本地多语种 Whisper GGML 模型，完成麦克风采集、本地人声检测、中文
最终转写、带采集时间点的本地时间线投影；整个验收过程不产生应用出网。

**状态：** 本清单是 M2.3 的人工验收记录，不是模型下载说明，也不是质量宣传材料。代码
编译或离线测试通过，不能替代一次真实麦克风、真实模型和真实设备上的通过记录。

**范围：** 验收 `webrtc-vad` 的本地人声门控、`whisper-rs`/whisper.cpp 的本地中文
转写、模型 SHA-256 复验、时间线最终记录、停止收尾、输入中断和默认零出网。

**明确不在范围内：** 自动说话人区分、自动聚类、声纹/语音档案、真实身份识别、跨会话
关联、重叠说话分离、云 ASR、模型自动下载、PCM/嵌入导出，以及 Agent 或 HTTP 工具
执行。当前时间线中的“未归类”或人工创建的匿名簇，不代表自动识别出某个人。

---

## 验收原则

1. **先显式选择，再开始采集。** 导入模型不等于启用模型。未选择、类型不匹配、格式
   不匹配、文件被替换或无法加载时，开始真实录音必须在触及麦克风前失败，不能生成
   synthetic 文本，也不能回退到云端或系统服务。
2. **模型由用户在应用外准备。** WordCovenant 不提供模型 URL、不下载、不更新模型，
   也不因导入、验证、加载或转写而连接网络。验收人自行从可信来源取得模型及其元数据。
3. **仅接受兼容的多语种 GGML 模型。** 登记的 `input_format` 必须精确为
   `whisper.cpp-ggml`。当前 `whisper-rs` 运行时按 GGML 文件魔数加载，不接受 GGUF；
   文件扩展名不是格式或可信度证明。
4. **证据留在本机。** 原始 PCM、模型内容、转写文本和网络观察结果不上传。保留本地
   截图、会话 ID、模型登记 ID、构建 SHA、审计/间隙 ID 与必要的匿名说明即可。
5. **零出网优先。** “允许出网”会话开关在开始前、验收中和重启后均必须关闭。即使
   将来存在批准记录，关闭开关仍应阻断任何网络路径；M2.3 本身没有 HTTP 客户端、
   下载器或云端回退。

## 前置条件

- [ ] 在 macOS 真机上执行，并记录机器型号、芯片架构、macOS 完整版本和当前构建 SHA。
- [ ] 使用当前待验收的 WordCovenant 构建；不要把不同构建、不同模型或不同设备的结果
  混合为一次通过记录。
- [ ] 准备至少一个可用的 16 kHz 或 48 kHz 单声道/常规输入路径。若能取得两类设备，
  分别执行 16 kHz 与 48 kHz 场景；不支持的采样率必须记录为明确拒绝，不能当作通过。
- [ ] 准备一个由验收人自行获得的**多语种** Whisper GGML 单文件模型，以及可信模型
  元数据中的 SHA-256、版本、模型卡标识和许可证标识。不要把小语种/仅英文模型、GGUF
  或未经校验的临时转换文件作为通过样本。
- [ ] 使用本机 SHA-256 工具独立计算待导入文件的摘要，并与可信元数据逐字符核对。记录
  文件大小、计算值和元数据来源说明；不要把完整模型路径写入审计、截图公开内容或问题
  单。
- [ ] 关闭其他会占用麦克风的应用。在安静环境准备一段自然中文短句、一段持续静音，以及
  可控的停止录音和设备中断操作。
- [ ] 关闭“允许出网”开关，退出并重启应用后再次确认其关闭。启动本地进程级网络观察；
  观察工具、PID、开始时间与结束时间必须被记录。
- [ ] 已完成适用的 M1/M2.2 采集生命周期验收，或对未执行项保留可复测的硬件/系统阻断
  说明。本清单不取代输入权限、时钟与背压基础验收。

### 固定记录字段

每个场景开始前和结束后均填写以下字段；“失败”或“阻断”必须保留实际观察，不得只写
结论。

| 字段 | 记录内容 |
| --- | --- |
| 执行人 / 日期 / 时区 | 执行人代号、当地日期和时区 |
| 机器与系统 | Mac 型号、芯片、macOS 完整版本 |
| 应用与构建 | 应用版本、debug/release、构建 SHA |
| 输入设备 | 设备名称/UID、实际采样率、声道数 |
| 本地模型 | 匿名模型登记 ID、版本、`whisper.cpp-ggml`、文件大小、SHA-256 前后缀 |
| 许可证证据 | 模型卡标识、许可证标识、确认时间 |
| 会话与时间 | 会话 ID、开始/停止本地时间、关键操作时间 |
| 观察结果 | 可见状态、时间线条目数、时间点、gap/event ID、实际文本是否符合预期语义 |
| 网络证据 | 观察工具、PID、窗口、连接数、出网相关审计记录数 |
| 结果 | 通过 / 失败 / 阻断 / 不适用，以及复测编号 |

## 场景 A：模型导入、格式与哈希复验

**步骤**

- [ ] 在应用外计算模型 SHA-256，并与可信元数据核对。
- [ ] 从原生文件选择器主动选择该本地文件；取消一次选择以确认取消不产生导入。
- [ ] 填写语音识别类型、版本、`whisper.cpp-ggml` 输入格式、预期 SHA-256、模型卡与
  许可证标识，并显式确认许可证。
- [ ] 完成导入后，确认模型仅显示为本地登记信息，不显示绝对文件路径、原始模型内容或
  PCM。
- [ ] 在应用内显式选择该已导入模型，记录所选模型的匿名登记 ID。
- [ ] 另行尝试导入或选择一个错误元数据样本：错误 SHA-256、`gguf` 格式或非语音识别
  类型三者任选其一；该步骤可在单独测试文件/会话中进行。

**预期**

- [ ] 导入只读取本机文件，不出现下载、URL、远程模型或网络授权请求。
- [ ] 正确样本的哈希、大小、许可确认和模型登记均成功；导入本身不自动选为活动 ASR。
- [ ] 只有已选择的、语音识别类型且格式精确为 `whisper.cpp-ggml` 的登记可用于后续启动。
- [ ] 错误哈希、GGUF 或错误模型类型在开始录音前被拒绝；不创建 synthetic 转写，也不
  回退到任何网络/系统识别服务。

**必须记录**

- [ ] 导入前独立计算的 SHA-256、登记结果、活动模型 ID、错误路径的拒绝信息与本地截图。
- [ ] 导入和拒绝期间网络观察的连接数（应为零）。

## 场景 B：未选择或不可用模型时的失败关闭

**步骤**

- [ ] 退出并重新启动应用，使其回到没有活动 ASR 模型选择的初始状态；或使用一个未登记
  模型 ID 的测试状态。
- [ ] 主动点击开始真实记录。
- [ ] 恢复一个正确选择后，临时替换、截断或移走应用管理目录中的已导入模型文件，再次
  尝试开始记录；完成后恢复原文件或重新导入。

**预期**

- [ ] 未选择模型时，应用明确提示必须选择兼容的本地 Whisper 模型，且不进入真实录音。
- [ ] 文件缺失、大小/摘要不匹配或无法加载时，应用在启动采集前失败关闭；不创建伪造
  会话、时间线文本或连续采集时钟。
- [ ] 错误不会被隐藏为“识别成功但没有文本”，不会触发模型下载或出网。

**必须记录**

- [ ] 每次开始请求的状态、错误、是否出现麦克风权限请求、会话/时间线是否变化、模型
  复验失败类型和网络观察结果。

## 场景 C：首次主动录音与麦克风允许

**步骤**

- [ ] 在有效模型选择和“允许出网”关闭状态下启动应用；不要先开始录音，确认无权限弹窗。
- [ ] 主动点击开始记录，在 macOS 权限弹窗中选择“允许”。
- [ ] 对着选定设备说一段自然中文（建议 10 至 20 秒），中间保留 1 至 2 秒正常停顿。
- [ ] 保持录音，等待时间线出现最终转写；记录每个最终条目的采集时间点和墙上时间显示。
- [ ] 停止记录并确认会话进入停止状态。

**预期**

- [ ] 权限只在用户主动开始时请求；允许后状态由启动阶段进入实际 `Recording`，电平表对
  说话有响应。
- [ ] WebRTC VAD 在本地将语音段送入本地 Whisper；时间线只出现最终记录，不出现 fixture
  或 synthetic 文本。每条最终记录包含有序、有效的采集开始/结束时间点。
- [ ] 最终文本的语言与所说中文在语义上可辨认；此观察仅证明本次模型/设备路径可用，
  不构成 CER/WER、延迟、跨说话人或覆盖率承诺。
- [ ] 停止后已接纳的工作有一次受限的收尾机会；最终成为转写或带范围的 inference gap，
  不静默丢失，也不会在会话停止后写入下一会话。
- [ ] 全程没有网络连接、模型下载、HTTP 工具或出网审计记录。

**必须记录**

- [ ] 权限弹窗时间、状态序列、首次有电平时间、每个最终条目的捕获范围、会话 ID、停止
  时间、最终/间隙数量和时间线截图。

## 场景 D：拒绝麦克风权限

**步骤**

- [ ] 在可重置的权限环境中主动开始记录，在系统弹窗中选择“不允许”。
- [ ] 重试一次开始记录，并退出/重启后再次验证。

**预期**

- [ ] 应用显示明确的非录音状态和权限错误；无伪造电平、模型执行、会话、转写或连续时间线。
- [ ] 重试和重启不绕过 macOS 授权；不触发出网或模型下载。

## 场景 E：16 kHz 与 48 kHz 输入路径

**步骤**

- [ ] 使用实际提供 16 kHz 的输入路径重复场景 C 的短中文语句与停止步骤。
- [ ] 使用实际提供 48 kHz 的输入路径重复相同步骤；记录每次设备的实际格式。
- [ ] 如设备只能提供不受支持的采样率（例如 44.1 kHz），尝试一次并记录应用的处理方式。

**预期**

- [ ] 16 kHz 与 48 kHz 均可产生有序的本地最终转写或明确、可审计的范围终态。
- [ ] 48 kHz 路径在原生内存完成既有受限转换；PCM 不进入 WebView、SQLite、审计记录或日志。
- [ ] 未支持的采样率被明确拒绝，不以错误重采样、静默降级或伪造正常会话冒充支持。

**必须记录**

- [ ] 输入格式、状态序列、最终条目/间隙范围、转写可辨认性观察、拒绝信息和设备限制。

## 场景 F：静音、人声边界与停止中的语句

**步骤**

- [ ] 开始录音后保持至少 10 秒安静，期间不要说话或播放语音。
- [ ] 随后说一段短中文，再保持 2 至 3 秒静音，重复两次。
- [ ] 在最后一句话尚未完全结束时主动点击停止记录。

**预期**

- [ ] 静音不产生伪造中文文本；若本地模型输出空结果，时间线不会填充占位语句。
- [ ] 人声片段在有界 pre-roll/hangover 后形成最终转写或明确范围的失败/背压 gap；多段
  记录的采集范围不倒退、不重叠为无效区间。
- [ ] 停止中的已封口片段被收尾处理；无法在预算内完成时记录有范围的终态，而非静默缺失。

**必须记录**

- [ ] 静音期间条目数、每段语句的采集范围、停止操作时间、最终/间隙结果与对应审计证据。

## 场景 G：输入设备中断与恢复

**步骤**

- [ ] 使用有效模型和输入设备开始录音并说话数秒。
- [ ] 录音中拔出 USB 设备、关闭蓝牙输入、在系统中切走输入，或执行另一种可复现的来源中断。
- [ ] 等待状态稳定后重新连接或切换设备，按 UI 指引恢复/重新开始记录。

**预期**

- [ ] 输入中断显示为 `Interrupted`、`Failed` 或明确恢复状态，并产生可追溯的 capture 或
  inference gap；中断区间不得被伪装成连续录音或连续转写。
- [ ] 恢复后的采集使用新的真实时钟段；旧 runtime generation 的结果不能写入新会话。
- [ ] 中断与恢复不会自动改选模型、启用出网、下载模型或调用远程识别。

**必须记录**

- [ ] 中断/恢复时间、设备 UID、状态变化、gap/event ID、旧结果拒绝或新时钟段证据。

## 场景 H：零出网观察

**步骤**

- [ ] 在进程级网络观察持续运行时，执行场景 A 至 G 的适用部分；全过程不打开“允许出网”。
- [ ] 退出并重启应用后再次观察一次空闲、导入、选择、开始、停止路径。
- [ ] 查看本地状态/审计投影中与出网相关的记录。

**预期**

- [ ] 观察窗口内应用进程的出站连接数为零；没有模型下载、DNS/HTTP 重试、云 ASR 或工具
  调用。
- [ ] 每次重启后出网开关仍关闭。即使将来存在出网审批，本次路径也不会建立连接。
- [ ] 导入、SHA-256 校验、模型加载、VAD、Whisper、时间线写入和审计全部可在离线环境完成。

**必须记录**

- [ ] 网络观察工具、PID、时间窗口、连接数、每次启动的开关状态与出网相关审计记录数。

## M2.3 通过条件

- [ ] 场景 A 至 H 在同一可识别构建上完成，或每项不适用都有具体硬件/系统限制和复测计划。
- [ ] 正确的本地多语种 `whisper.cpp-ggml` 模型能被导入、哈希复验、显式选择，并在真实
  麦克风的 16 kHz/48 kHz 路径上得到有时间点的中文最终记录。
- [ ] 静音、无模型、错误格式、哈希篡改、权限拒绝、停止中的语句和输入中断均形成正确的
  明确结果；没有 synthetic 文本、无声丢弃、伪造连续时间线或跨会话迟到写入。
- [ ] 原始 PCM、模型绝对路径和原始模型字节未出现在 WebView、SQLite、审计记录或日志中。
- [ ] 出网开关全程关闭，进程级网络观察和本地审计均证明零出网。
- [ ] 验收记录明确写明：本里程碑**不支持自动说话人区分、声纹识别或真实身份识别**；
  人工匿名簇修正不构成自动分离证据。

## M2.3 阻断条件

- [ ] 未显式选择兼容模型仍可开始真实录音，或错误/篡改模型被接受。
- [ ] 导入或录音过程中下载模型、连接云 ASR、调用 HTTP 工具，或在开关关闭时产生任何出网。
- [ ] 静音产生 synthetic/占位文字，或真实语音没有最终记录也没有范围明确的终态。
- [ ] 停止、背压或设备中断后出现无界资源增长、无声丢弃、伪造连续时间线、重复 final，
  或旧会话结果进入新会话。
- [ ] PCM、绝对模型路径、模型字节或嵌入进入 WebView、SQLite、审计记录、日志或网络请求。
- [ ] 将匿名簇、文本、音量、音高或任何启发式结果描述为自动说话人区分、声纹匹配或身份结论。

## 失败恢复与复测

1. 立即停止录音，确认“允许出网”关闭，并保留当前构建 SHA、会话 ID、模型登记 ID、
   状态截图、gap/event ID 和网络观察窗口。
2. 不修改原始本地证据。需要复测时创建新会话、使用新的复测编号，并明确模型、设备或
   构建是否变化。
3. 对模型问题，重新从可信本地副本计算 SHA-256 后再导入；不要在应用内寻找下载或更新
   路径。
4. 对权限问题，先退出应用，再由验收人主动按 macOS 系统流程恢复或重置该应用的麦克风
   权限，然后重新开始场景；该操作不应改变本地审计结论。
5. 只有阻断修复并在同一构建或明确记录的新构建 SHA 上复测通过，才能更新 M2.3 状态。
