# WordCovenant

> 凡口头所言，皆立为契约，有据可查，事事落单。

WordCovenant 是一款 macOS 优先、本地优先的桌面工作台，用于可见的对话采集、带时间戳的文字记录、匿名说话人簇，以及由用户主动触发的 Agent 动作。

## 隐私约定

- 音频、转写文本、说话人数据和上下文默认留在设备本地。
- 默认拒绝网络出站。只有用户可见地启用仅本次会话有效的出网总开关，并分别批准具名工具、其 HTTPS 源站和数据范围后，才允许出网。
- 转写文本、模型、技能、钩子或外部响应本身都不能授予权限。
- Agent 计划是强类型数据，而不是 shell 命令，不能绕过 Rust 的策略检查。
- 当前版本不会通过声纹自动识别真实身份，也不宣称具备法律上的不可否认性。

## 当前基础能力（M0 至 M2.2）

- WordCovenant 的 macOS 应用品牌、受限的 Tauri capability 集合，以及不包含通配网络源的 CSP。
- 本地录音工作台，始终可见的本地优先/录音状态，以及按时间顺序排列的转写时间线。
- 用于采集会话、可修订转写片段、匿名说话人簇、计划与工具调用的 Rust 领域契约。
- 默认拒绝的 HTTPS 出站策略，包含可见的仅本次会话总开关，以及精确源站、数据范围、到期和撤销检查。
- 通过 SQLite 在本地持久化的仅追加 SHA-256 审计链。
- 有界音频采集契约、采样时钟时间换算、明确的音频间隙类型，以及可重复的测试采集源。
- 用于会话生命周期、时间线查询、出网批准与撤销、本地动作提议和网络策略预检的强类型 Tauri 命令。

为了能在浏览器中直接查看，M0 UI 会在 Tauri 之外使用本地合成数据。界面会明确标注为 `synthetic`；这不是麦克风或 ASR 的降级替代方案。

## M2：本地模型导入

- 模型文件必须由用户通过原生文件选择器明确选取；取消选择不会产生导入请求。
- 导入仅处理本机文件，必须提供模型卡、确认许可证，并填写用于校验的预期 SHA-256。
- 模型会复制到应用本地存储；导入过程不发起网络请求，也不下载任何模型。
- WebView 没有通用文件读取权限；所选源路径仅用于本次导入，不会写入模型登记或审计记录。
- 目前已具备本地模型登记和离线推理契约；真实原生 ASR 运行时仍是后续工作。

## M3.0：手动匿名说话人修正

M3.0 的代码已实现，现处于完整离线验收就绪状态。它只提供会话内、人工发起的匿名归类修正：

- 可在单个会话中创建不含身份信息的匿名说话人簇；初始编号和用户重命名都只是显示元数据。
- 说话人名称、簇记录和改派记录均为本地 SQLite 中仅追加的修订，并与本地审计链绑定。
- 仅可将当前最终版转写片段改派到一个活动匿名簇，或改回“未归类”；改派会保留原始文本、采集时间、墙上时钟时间和模型来源，并追加 `UserEdited` 转写修订及审计事件。
- 桌面端提供扁平的匿名说话人管理面板；冲突、过期修订、非最终片段、跨会话或无效簇均会被拒绝，不会静默覆盖记录。

M3.0 **不**提供自动说话人分离或自动聚类。嵌入向量、声纹/语音档案、声纹匹配、跨会话关联、置信度、重叠说话判定和任何真实身份声明均不在当前范围内。用户输入的名称也不代表系统确认了某个人的身份；合并和拆分的端到端用户操作同样尚未提供。

原始 PCM 不会暴露给 WebView，也不会写入 SQLite、审计记录或日志；M3.0 不提供 PCM 查看、导出或 IPC。此功能没有新增网络客户端、模型下载或出网请求。应用启动时仍默认拒绝出网，只有用户在可见的本次会话开关中主动启用，并另行通过精确工具、HTTPS 源站和数据范围审批后，未来获准的功能才可能出网。

## 后续里程碑

M0 实现计划见 [docs/plans/2026-08-07-word-covenant-local-first-mvp.md](docs/plans/2026-08-07-word-covenant-local-first-mvp.md)。完整的产品路线图、里程碑、验收门槛、风险和架构决策见 [docs/plans/2026-08-07-word-covenant-roadmap.md](docs/plans/2026-08-07-word-covenant-roadmap.md)。

2. M1 新增 CoreAudio 采集、真实会话时钟，以及可见的音量与音频间隙事件。

## 开发

前置条件：较新的 Rust 工具链、pnpm、Xcode 命令行工具，以及常规的 Tauri macOS 开发环境。

```sh
pnpm install
pnpm test --run
pnpm type-check
pnpm check
pnpm tauri dev
```

可在浏览器中单独运行预览，地址为 `http://127.0.0.1:1420`：

```sh
pnpm vite:dev
```

### 开发模拟输入

在 `pnpm tauri dev` 的开发构建中，可通过录音控制旁的波形图标选择“开发模拟音频输入”，再使用正常的“开始记录”按钮运行一段本地脚本化会话。它会按采样时钟逐步生成 `synthetic` 转写、匿名说话人标签和本地审计记录，不请求麦克风权限，也不会出网。模拟标签只是 fixture；该能力仅用于验证会话与界面流程，不代表真实麦克风、ASR、自动说话人分离、声纹或身份识别已经完成。

## 验证

```sh
pnpm test --run
pnpm type-check
pnpm build
cargo test --manifest-path src-tauri/Cargo.toml
cargo check --manifest-path src-tauri/Cargo.toml
```

测试覆盖默认拒绝出网、授权匹配、过期、撤销、转写时间戳边界、审计链篡改检测、本地采集队列行为，以及可见的本地优先 UI 状态。M3.0 额外覆盖匿名簇与标签的仅追加修订、审计绑定、最终片段改派、乐观并发冲突和前端拒绝状态；这些测试不等同于自动说话人分离、声纹或真实身份能力的验收。
